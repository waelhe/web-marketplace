## نواتج الطور (4 مهام، كل واحدة ببوابة)

### ن1 — الحركة على الفعل (أساس كل تفاعل)
`transition` على: hover/active/focus-visible للأزرار والبطاقات والروابط، `open/close` للقوائم، **تحت `prefers-reduced-motion: reduce` تُلغى كاملة** (القاعدة موجودة، تُوسَّع). ممنوع: entrance animations، transform يرفع التخطيط، easing عشوائي.
- **قياس**: `grep transition` ≥ 8 + لقطة hover (focus ring ثابت، بلا قفزة).

### ن2 — شريط المميّز الكهرماني (اللمسة الوحيدة)
`--accent` كـ **حافة** (inline-start 3px) + خلفية `--surface` دافئة على شريط `إعلانات مميزة` فقط (لا شارات مكرّرة). **الشرط:** لا يُبنى إن لم يكن هناك محتوى مميّز مُقاس (قاعدة: لا زخرفة لبلا بيانات) — يُخفي إن `content.length === 0`.
- **قياس**: بصري (حافة كهرمانية واحدة) + SSR HTML ( PresentStrip موجود فقط مع بيانات).

### ن3 — ترويسة/تنقّل مصمَّم (responsive حقيقي)
 behaviors صريحة: على `< 640px` (: ذلку في CSS عدا الشاشة) — الشعار وعمود واحد، التنقّل ينزلق أفقياً (overflow-x مع scroll-snap)، لا التفاف عشوائي. أضف **أول** `@media (min-width/max-width)` حقيقي في المشروع (اليوم صفر breakpoints).
- **قياس**: عرض 375px و1440px بلا تجاوز أفقي (اختبار Playwright: `scrollWidth <= clientWidth`).

### ن4 — أيقونات + إتاحة النماذج
1. **4 أيقونات SVG مضمّنة** (سهم مشاركة، نجمة، رسالة، قلب) كـ server components بـ `aria-hidden` أو نص مكافئ — صفر emoji، صفر اعتماد.
2. **أخطاء حقول النماذج**: `aria-invalid` + `aria-describedby` + رسالة حقل في نماذج الحجز/الملف (2 → كل نموذج كتابة رئيسي).
- **قياس**: `aria-*` 9 → ≥ 18، `svg` 0 → ≥ 4، اختبار: نموذج حجز يرفض قيمة ويحمل نص خطأ مقروء.
